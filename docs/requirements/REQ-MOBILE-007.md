# REQ-MOBILE-007 移动端轴坐标间距更小

- 状态: 待办
- 优先级: P1
- 类型: 外部
- 来源: 口头（领导）
- 提出日期: 2026-08-04
- 关联: REQ-MOBILE-008（设备判定）

## 背景 / 问题

移动端的轴坐标间距值应该比 PC 端**小**，才方便观察数据。要求展示的蜡烛图在**合理大小**内。

## 需求描述（领导原话要点）

1. 移动端轴坐标间距值应**小**，比 PC 端小，方便观察数据。
2. 展示的蜡烛图应在**合理大小**内。

## 验收标准（待补充）

- [ ] 移动端时间轴/价格轴间距明显小于 PC 端
- [ ] 蜡烛图宽度/高度在移动端屏幕下合理、可读
- [ ] PC 端间距不受影响

## 备注

- 现有 `barSpacing` 初始为 7（`ChartPanel.tsx` createChart `timeScale.barSpacing: 7`），zoom 按钮按 0.8/1.25 缩放。
- 移动端应调小 `barSpacing`（如 4-5）或设更小的 `rightPriceScale` 间距，让单位屏宽容纳更多 K 线。
- "合理大小"无客观标准，需在真机/设备视口下目测确认。
