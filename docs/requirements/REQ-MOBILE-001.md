## 背景 / 问题

移动端图表当前只能竖屏看，K 线可读性差。领导要求支持横屏观看模式，作为本周三上开发环境演示的主功能。

## 验收标准

- [x] 点击按钮进入横屏观看模式，图表随之横屏铺满
- [x] 支持返回竖屏
- [x] 横屏模式下图表可正常交互（缩放 / 平移）
