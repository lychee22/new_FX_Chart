# REQ-MOBILE-005 移动端单副图 + 副图描述

- 状态: 待办
- 优先级: P0
- 类型: 外部
- 来源: 口头（领导）
- 提出日期: 2026-08-04
- 关联: REQ-MOBILE-004（默认副图）

## 背景 / 问题

移动端只能允许展示**一个 pane**（一个副图）。从设置里选择下层技术分析指标后，**每次选择都重绘该 pane**（替换，而非累积）。主图与副图间隔处需要插入**关于副图的描述**——类似股票行情样式，股票会在左上角展示"成交量 XXX手"。

## 需求描述（领导原话要点）

1. 移动端**只能允许展示一个 pane**。
2. 从设置里选择下层技术分析指标，**每次选择后重绘 pane**（单选替换）。
3. **主图与副图间隔**插入副图描述，类似股票左上角"成交量 XXX手"。

## 验收标准（待补充）

- [ ] 移动端同一时刻只有一个副图 pane
- [ ] 设置里切换下层指标时，旧的被替换重绘
- [ ] 主图与副图之间显示副图描述（指标名 + 值），样式类似股票行情

## 备注

- 现有 `.pane-title-overlay` 已实现"指标名 + 实时值"（`ChartPanel.tsx` 浮层，桌面端显示），但移动端被 CSS `@media (max-width:768px)` 隐藏——需评估是复用（去掉操作按钮）还是新建移动端样式。
- "重绘 pane" 的替换逻辑：App 的 `toggleLower` 是累积多选，移动端需改为单选替换，或 ChartPanel 侧在移动端只加载一个。
- 副图描述里的值格式："成交量 XXX手"是股票单位，外汇副图指标（RSI/MACD 等）值单位不同，需确认展示格式。
- 注意横屏全屏时副图标题浮层被隐藏（REQ-MOBILE-001 A1），此需求与横屏模式的关系需协调。
