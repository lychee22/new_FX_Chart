# REQ-MOBILE-008 移动端判定改为设备类型

- 状态: 待办
- 优先级: P1
- 类型: 外部
- 来源: 口头（领导）
- 提出日期: 2026-08-04
- 关联: REQ-MOBILE-004（布局切换重置）

## 背景 / 问题

目前切换移动端展示策略是按照**设备长宽比/宽度**判定（`useIsMobile` 用 `@media (max-width: 768px)`）。建议改为**根据设备是否是电脑**来配置（即按设备类型判定）。

## 需求描述（领导原话要点）

1. 目前移动端展示策略是**按设备长宽比**判定。
2. 建议换成**根据设备是否是电脑**来配置。

## 验收标准（待补充）

- [ ] 移动端判定基于设备类型（电脑/非电脑），而非窗口宽度
- [ ] 电脑上即使窗口很窄也走桌面端布局
- [ ] 非电脑设备（手机/平板）走移动端布局

## 备注

- 现状：`useIsMobile`（`frontend/src/hooks/useIsMobile.ts`）用 `window.matchMedia('(max-width: 768px)')`，且 main.css 的样式也用同样的 `@media (max-width: 768px)` 断点。
- 改设备类型判定影响面大：
  - `useIsMobile` 逻辑（UA 检测 / `navigator.userAgentData` 的 `mobile` 标志等）
  - **CSS 断点** `@media (max-width:768px)` —— 若只改 JS 判定但 CSS 仍按宽度，会不同步
  - 横屏手机宽度 >768px 时当前会切到桌面布局，按设备类型判定后横屏手机保持移动端布局（与 REQ-MOBILE-001 横屏体验一致）
- 这是基础层改动，会影响 REQ-MOBILE-004/005/007 的实现方式，建议先定方向。
